STORE LISTING TAB
========================================================================

Description (the summary line comes from manifest.json):

Birdify brings the blue bird back to X.

It restores classic Twitter branding across the English X website:

• The blue bird replaces the X logo in the header, on the loading screen and in your browser tab.
• Tab titles and interface labels say Twitter again.
• Post and Repost become Tweet and Retweet, capitalized the way Twitter wrote them: Show 31 Tweets, Quote Tweet, Undo Retweet.
• Premium becomes Twitter Blue. The renamed Chat and History items read Messages and Bookmarks.
• Notifications read "Retweeted your Tweet".

You choose what comes back. Separate switches control the Twitter name, the blue bird and Tweet wording, and one switch pauses everything. Turn it off and the page goes back to how X shows it.

Birdify leaves tweets, people's names, direct messages, links and the text you type exactly as written. It updates the page as you scroll and navigate, without polling.

Private by design: everything runs in your browser. Birdify stores four on/off settings locally and sends nothing anywhere. No analytics, no tracking, no account access.

Works on x.com and twitter.com, including their www and mobile subdomains. English interface wording is supported.

========================================================================
AUTOMATIC UPDATES AFTER THE FIRST VERSION
========================================================================

After Google approves the first version, later releases can be submitted by the release workflow. Add these repository secrets (GitHub: Settings > Secrets and variables > Actions):

  CWS_PUBLISHER_ID   Publisher ID shown in the Developer Dashboard account settings
  CWS_ITEM_ID        The item ID (the 32-letter ID in the item's dashboard URL)
  CWS_CLIENT_ID      OAuth client ID from a Google Cloud project with the Chrome Web Store API enabled
  CWS_CLIENT_SECRET  That OAuth client's secret
  CWS_REFRESH_TOKEN  A refresh token for your Google account with the
                     https://www.googleapis.com/auth/chromewebstore scope

Google's guide covers creating the OAuth client and refresh token:
https://developer.chrome.com/docs/webstore/using-api
